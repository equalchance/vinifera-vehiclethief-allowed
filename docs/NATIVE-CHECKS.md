# Native results

Eight native runs passed 389 assertions with zero failures using the matched
runtime. Assertions repeat across runs; they are not 389 distinct scenarios.

Coverage includes both theft paths, forced orders, candidate selection,
navigation queues, regressions, baseline controls, and cold save/load.
The checks use controlled object state and positions.

See the [summary](../checks/native-acceptance-summary.json) and
[per-run checks and input hashes](../checks/native-runs/).
Optional probe source is under `diagnostics/`.

These results do not establish autonomous pursuit, normal flight, completed
deployment transformation, or detailed multiplayer instrumentation.
